# XYZ座標表示システム 実装概要

## 概要

Hyperの技術を参考に、屋内測位システムに3D座標表示機能を追加しました。このシステムは、X、Y、Z座標をリアルタイムで表示し、座標履歴の可視化と統計情報の提供を行います。

## 実装されたコンポーネント

### 1. データモデル

#### Coordinate3D
- 3D座標系を定義するデータクラス
- X、Y、Z座標（メートル単位）
- 精度、タイムスタンプ情報
- 距離計算、座標変換メソッド

#### UserPosition3D
- 3Dユーザー位置を表すデータクラス
- 2D位置から拡張（Z座標、フロア情報追加）
- 信頼度、不確実性情報
- フロア間移動、高度変化検出機能

#### IndoorMap3D
- 3D屋内マップ構造
- 高さ方向のサイズ情報
- 3D壁、3D POIサポート
- フロア番号、基準高さ情報

### 2. 座標変換システム

#### Coordinate3DTransformer
- 物理座標 ↔ 画面座標変換
- フロア間座標変換
- 表示可能性チェック
- ビュー中央配置機能

#### Transform3DCoordinatesUseCase
- 3D座標変換のビジネスロジック
- 複数の変換操作をサポート
- エラーハンドリング

### 3. UIコンポーネント

#### Coordinate3DDisplay
- 3D座標情報の表示
- X、Y、Z座標の色分け表示
- 信頼度インジケーター
- フロア、精度、方位、速度情報

#### Coordinate3DAxes
- 3D座標軸の視覚的表示
- X軸（赤）、Y軸（緑）、Z軸（青）
- 軸ラベル表示

#### CoordinateHistoryGraph
- 座標履歴のグラフ表示
- 移動軌跡の可視化
- 統計情報表示
- グリッド、凡例機能

### 4. 画面

#### CoordinateDisplayScreen
- メイン座標表示画面
- 3D座標軸、現在位置、履歴グラフ
- 統計情報、操作ボタン
- ローディング、エラー状態管理

### 5. ViewModel

#### CoordinateDisplayViewModel
- 座標データの管理
- リアルタイム座標更新
- 履歴管理、エクスポート機能
- エラーハンドリング

## 主要機能

### 1. リアルタイム座標表示
- 現在のX、Y、Z座標をリアルタイム表示
- 信頼度に基づく色分け表示
- 精度、フロア、方位、速度情報

### 2. 座標履歴可視化
- 移動軌跡のグラフ表示
- 統計情報（総移動距離、平均精度など）
- データポイントの色分け（信頼度別）

### 3. 3D座標軸表示
- 直感的な座標系の視覚化
- X、Y、Z軸の色分け表示
- 軸ラベル

### 4. データ管理
- 座標履歴の保存・管理
- 履歴のクリア機能
- CSV形式でのエクスポート

### 5. 設定・制御
- 座標更新の開始/停止
- 更新間隔の調整
- エラー時の再試行

## 技術的特徴

### 4. エラーハンドリング

## 使用方法

### 1. 画面への遷移
```kotlin
// 座標表示画面への遷移
navController.navigate("coordinate_display")
```

### 2. 座標データの取得
```kotlin
// ViewModelから座標データを取得
val position by viewModel.currentPosition.collectAsState()
val history by viewModel.positionHistory.collectAsState()
```

### 3. 座標変換の実行
```kotlin
// 3D座標変換の実行
val result = transform3DCoordinatesUseCase.invoke(
    Transform3DCoordinatesUseCase.Params(
        operation = TransformOperation.METERS_TO_SCREEN,
        x = 10f, y = 20f, z = 5f
    )
)
```

## まとめ

XYZ座標表示システムは、Hyperの技術を参考に、屋内測位システムに3D座標機能を追加しました。リアルタイム座標表示、履歴可視化、統計情報提供により、ユーザーに直感的で詳細な位置情報を提供します。Androidシステムに依存しない汎用的な設計により、他のプラットフォームへの移植も容易です。
